# Screenshots (optional)

PulseTrace is designed to be **evaluated without images**. Reviewers can rely on this repository’s documentation, API (`/docs` in development), automated tests, and the [ShopFlow demo walkthrough](../DEMO_WALKTHROUGH.md).

**E2E captures** used in the root README live in [`e2e/`](e2e/) (dashboard, incidents, RCA). They were produced from real Playwright runs—not mock or AI-generated UI.

Additional filenames you may add locally:

| File | Screen |
|------|--------|
| `e2e-overview.png` | Combined overview (optional) |

No step in installation or demo **requires** saving new screenshot files.
